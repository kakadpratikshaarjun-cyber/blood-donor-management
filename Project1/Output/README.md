# Output

## Blood Donor Management System Using Linked List

The program successfully performs all the required operations for managing blood donor records using a singly linked list.

### Main Menu

The program provides the following options:

1. Add Donor
2. Delete Donor
3. Search Donor
4. Display All Donors
5. Exit

### Add Donor

The user enters the Donor ID, Name, Age, Blood Group, and Contact Number.

After entering the details, the program displays:

**Donor added successfully.**

### Display All Donors

The program displays all the donor records stored in the linked list, including:

- Donor ID
- Name
- Age
- Blood Group
- Contact Number

### Search Donor

The user enters a blood group. The program searches the linked list and displays all donors having the required blood group.

If no matching donor is found, the program displays:

**No suitable donor found.**

### Delete Donor

The user enters the Donor ID to delete a donor record.

If the donor is found, the program removes the record and displays:

**Donor deleted successfully.**

If the donor does not exist, the program displays:

**Donor not found.**

### Exit

When the user selects the Exit option, the program terminates and displays:

**Exiting program...**

## Result

The Blood Donor Management System successfully performs donor addition, deletion, searching, and display operations using a singly linked list.
