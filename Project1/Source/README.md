# Source Code

## Blood Donor Management System Using Linked List

This folder contains the C++ source code of the Blood Donor Management System.

The program is developed using a **Singly Linked List** to store and manage blood donor records.

## Source File

The main source code file is:

- `main.cpp`

## Functions Implemented

The program contains the following functions:

### Add Donor

Adds a new donor record to the linked list.

### Delete Donor

Deletes a donor record using the Donor ID.

### Search Donor

Searches for suitable donors based on their blood group.

### Display Donors

Displays all donor records stored in the linked list.

### Main Function

Provides a menu-driven interface through which the user can select different operations.

## Donor Information

Each donor record contains:

- Donor ID
- Name
- Age
- Blood Group
- Contact Number
- Pointer to the next donor

## Data Structure

The project uses a **Singly Linked List**.

Each donor is stored as a node, and every node contains a pointer to the next donor.
